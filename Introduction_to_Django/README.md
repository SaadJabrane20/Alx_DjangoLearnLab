# LibraryProject 📚

## Overview
LibraryProject is a simple Django project created to gain familiarity with Django's development environment and workflow.  
This project demonstrates how to create a new Django project, run a local development server, and explore the default project structure.

---

## Objectives
- Install and configure Django.
- Create a new Django project.
- Understand the purpose of key Django files and directories.
- Run and access the Django development server.

---

## Prerequisites
Before you begin, make sure you have:
- **Python 3.x** installed on your system.
- **pip** (Python package manager).
- A terminal or command prompt.
